Install in 30 seconds

  1. Download the ZIP above and extract it somewhere persistent (e.g. Documents\cs2-gencode\ or ~/cs-extension/). Don't delete the folder later — Chrome reads from it on every browser launch.
  2. Open Chrome and navigate to chrome://extensions/.
  3. Toggle Developer mode on (top-right switch).
  4. Click Load unpacked and select the folder you extracted in step 1.
  5. The CS2 GenCode icon appears in your toolbar. Pin it from the puzzle-piece menu so it's always visible.
  6. Open the popup → paste a CS2 inspect link → click Convert → the !ngk <code> command lands on your clipboard. Paste it in the dghq.app server chat to spawn the skin.

What you can do once it's installed

  • Convert any CS2 inspect link — masked, unmasked, or raw protobuf hex — into an !ngk chat command.
  • Click "!gen" buttons on supported sites (CSFloat, CS2 Inspects, Steam Community, Steam Marketplace, Skinport) — the extension auto-injects helper buttons next to inspect-link icons.
  • Sticker bombs work — up to 5 stickers per weapon with full free-placement rotation, scale, and X/Y offsets, plus charm/keychain support.
  • One-click connect — copies connect inspect.dghq.app to your clipboard so you can paste straight into the CS2 console to join the server.

Updating

When a new version drops, just re-download the ZIP, replace your extracted folder's contents with the new files, and click the ↻ refresh icon on the CS2 GenCode card at chrome://extensions/. Your settings are preserved automatically by Chrome's local storage.

Once Google approves the Web Store listing, you can switch to the public version for automatic updates — but feel free to stay on the unpacked install if you prefer.

"Disable developer mode extensions" warning

Chrome shows this warning every time you launch the browser while any unpacked extension is loaded. It's not a security alert — it's a nudge to use Web Store extensions instead. Click Cancel to keep the extension. The warning disappears once you switch to the Web Store version.

Troubleshooting

The popup says "API error: 401 Unauthorized"

The extension ships with the right key already. If you see 401, open the popup → ⚙ → "Advanced — override API key" and make sure that field is blank. A blank field means "use the bundled key." If you accidentally typed something, clearing it and clicking Save fixes it.

The popup says "Steam GC bot unreachable" for marketplace links

Marketplace and inventory links require a Steam Game Coordinator round-trip to decode (they only contain asset IDs, not item data). The bot occasionally disconnects from Steam and takes ~30 seconds to reconnect. Wait a moment and retry. Masked craft links (like ones from cs2inspects.com) decode fully offline and don't need the bot.

The !ngk command spawns the wrong skin / vanilla

That's a server-plugin issue, not the extension. Hop into the dghq.app Discord and report the inspect link plus the !ngk code that didn't work. The plugin is actively being patched.

Chrome refuses to load the unpacked extension

Make sure the folder you selected contains manifest.json at the top level (not nested inside another folder). If you double-click the ZIP and extract through Windows Explorer, sometimes you end up with cs2-gencode-1.0.0\cs2-gencode-1.0.0\ — select the inner one.
