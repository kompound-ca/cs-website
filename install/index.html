CS2 GenCode

Spawn any CS2 skin on dghq.app in two clicks

Chrome extension that turns any CS2 inspect link — masked, unmasked, marketplace — into an !ngk command you paste in the inspect.dghq.app server chat to spawn the skin.

What it does

🔗

Convert any inspect link

Masked craft links, unmasked Steam marketplace links, raw protobuf hex — all decoded into a single !ngk <code> command.

⚡

One-click "!gen" buttons

Auto-injects helper buttons next to inspect-link icons on CSFloat, CS2 Inspects, Steam Community, Steam Marketplace, and Skinport.

🎨

Full sticker / charm support

Up to 5 stickers per weapon with free-placement rotation, scale, and X/Y offsets. Charms / keychains too.

🎮

One-click server connect

Copies connect inspect.dghq.app to your clipboard so you can paste it straight into the CS2 console.

Install

One PowerShell line. Downloads the signed extension, opens Chrome to the extensions page, and tells you exactly what to click. About 30 seconds end-to-end.

iwr -useb https://cs2inspect.dghq.app/install.ps1 | iex

Manual install

Don't want to run the script? Download the signed .crx directly and drag it in.

⬇ cs2-gencode-1.0.0.crx (~70 KB)
  1. Open Chrome → chrome://extensions/.
  2. Toggle Developer mode ON (top-right switch).
  3. Drag the .crx file from your Downloads folder onto the Chrome extensions tab.
  4. Click Add extension on the confirmation dialog.
  5. Turn Developer mode OFF — the extension stays installed and Chrome stops showing the dev-mode warning popup on launch.
  6. Pin the CS2 GenCode icon from the puzzle-piece menu so it stays visible in your toolbar.

Use it

Open the popup → paste a CS2 inspect link → click Convert → the !ngk <code> command lands on your clipboard. Paste it in the dghq.app server chat and the skin spawns.

Or click the Inspect Server button in the popup to copy connect inspect.dghq.app, paste it into the CS2 console, and join the server.

Updating

Re-run the one-liner — it downloads the latest CRX and replaces the previous install (same extension ID, same settings preserved). Or grab the latest .crx manually and drag it onto chrome://extensions/.

Once the Chrome Web Store listing is approved you can switch to the public version for fully automatic updates. Stay on the side-loaded install if you prefer.

Troubleshooting

"This extension may have been corrupted" / refuses to install

Make sure Developer mode is toggled ON before you drag the .crx in. Chrome silently rejects self-signed CRX drag-installs when Dev mode is off.

The popup says "API error: 401 Unauthorized"

The extension ships with the right key already. If you see 401, open the popup → ⚙ → "Advanced — override API key" and make sure that field is blank. A blank field means "use the bundled key."

The popup says "Steam GC bot unreachable" for marketplace links

Marketplace and inventory links require a Steam Game Coordinator round-trip to decode (they only contain asset IDs). The bot occasionally disconnects from Steam and takes ~30 seconds to reconnect. Wait and retry. Masked craft links decode fully offline and don't need the bot.

The !ngk command spawns the wrong skin / vanilla

That's a server-plugin issue, not the extension. Hop into the dghq.app Discord and report the inspect link plus the !ngk code that didn't work.

PowerShell says "running scripts is disabled on this system"

The iwr | iex pattern doesn't trigger that because nothing is saved to disk as a .ps1. You're seeing this because you tried to run a downloaded .ps1 file directly. Use the one-liner instead, or run powershell -ExecutionPolicy Bypass -File install.ps1.
